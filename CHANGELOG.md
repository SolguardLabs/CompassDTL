# Historial de cambios

## 2.0.0 — 2026-10-23

- Cotización FX entera por ruta, curva de impacto de inventario configurable y score de liquidez en unidades de destino.
- Revalidación de límites vivos y comprobación de capital de la cola antes del pago.
- Liberación de reservas para tickets rechazados o expirados.
- Pruebas de liquidación FX, límite de exposición y conciliación de cuentas; documentación económica y operativa ampliada.

## 1.0.0

- Motor de rutas, cola de tickets, asientos y recibos deterministas.
- Modelo de capital, gobierno diferido, API JSON y SDK TypeScript.
